- When viewing a calendar event/job, show weather for that job location and install time window.

  - job address -> geocode to lat/lng
  - event startTime/endTime -> choose forecast closest to startTime (and optionally show window forecast)
- Weather display in Job Card:
  - current conditions (if same-day) or forecast for event time
  - temperature, precipitation chance, wind, and a small icon/summary
  - clearly label the forecast time used
- Weather should update automatically when:
  - event is moved to a different day/time
  - address is updated
- Implement caching to reduce API calls:
  - Cache by (lat,lng,date/hour bucket) in DB table WeatherCache or in-memory with TTL
  - TTL: 30–60 minutes for current; 3–6 hours for forecast
- Use one of these APIs (prefer simplest integration):
  - OpenWeather One Call (recommended) OR WeatherAPI.com
- Add env vars:
  - WEATHER_API_KEY
  - WEATHER_PROVIDER (optional)
- Create backend route:
  - GET /api/weather?jobId=...&eventId=... OR /api/weather?lat=...&lng=...&time=ISO
  - Response: { provider, timeUsed, temp, feelsLike, precipProb, windSpeed, summary, icon }
